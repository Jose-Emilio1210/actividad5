# Paint Shapes

Programa realizado en Python utilizando Turtle de un juego de memorama.

## Modificaciones realizadas

Se realizaron las siguientes mejoras al código inicial:

- Se centraron los dìgitos que están dentro de las tablas para que se vean mejor y corregir el tamamño.
- Se cambiaron los dígitos por palabras y cada palabra tiene colores distintos para mejorar la experiencia del usuario y ayudarlo a memorizar mejor.

## Ejecución

Ejecutar el programa con:

python memory.py
